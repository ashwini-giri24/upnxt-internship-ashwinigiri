TechNova is a simple and responsive e-commerce website developed using HTML, CSS and JavaScript as part of an internship project. The website allows users to browse products, view prices, and add items to a cart with real-time updates to the cart count and total amount. It features a clean user interface with sections like Home, About, Products, Cart, and Contact. The contact form includes basic validation and displays a success message upon submission. The design is mobile-friendly and includes smooth hover effects for better user experience. 
This project demonstrates fundamental front-end development skills, including layout design, responsiveness and basic JavaScript functionality for interactivity.
